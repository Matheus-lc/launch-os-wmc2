# Plano de contingência

## Grupo fraco

1. Enviar enquete simples.
2. Publicar áudio curto do Saizen com tese.
3. Transformar a principal dúvida em mini-aula.
4. Pedir resposta com número ou emoji simples.
5. Reforçar CTA de abertura sem vender pesado.

## Página ruim

1. Conferir carregamento mobile.
2. Colocar CTA acima da dobra.
3. Simplificar headline.
4. Mover prova para perto do preço.
5. Reduzir blocos longos.

## Anúncio caro

1. Pausar pior criativo.
2. Testar criativo com rosto e tese.
3. Trocar CTA para grupo.
4. Usar remarketing de engajados.
5. Reduzir orçamento até encontrar sinal.

## Checkout ruim

1. Testar link em modo anônimo e mobile.
2. Conferir preço, pix, cartão e parcelamento.
3. Remover cupom confuso.
4. Verificar entrega automática.
5. Acionar suporte Kiwify se houver erro real.

## Abertura sem vendas

1. Validar se o link abriu corretamente.
2. Checar cliques.
3. Enviar FAQ curto.
4. Publicar prova autorizada.
5. Gravar story simples do Saizen explicando para quem é.

## Problema técnico

1. Comunicar com calma no WhatsApp.
2. Usar link alternativo.
3. Registrar prints do erro.
4. Atualizar página se o erro for no site.
5. Não criar desconto por pânico sem decisão do coordenador.
