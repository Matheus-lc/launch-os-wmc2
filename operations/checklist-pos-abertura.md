# Checklist pós-abertura

Objetivo:
Manter a operação ativa após a abertura do carrinho em 05/06, sem lógica de fechamento planejado.

## Primeiras 24 horas após abertura

- [ ] Conferir se o checkout está funcionando.
- [ ] Conferir se Pix, cartão e boleto funcionam, se disponíveis.
- [ ] Registrar vendas por hora.
- [ ] Registrar dúvidas mais frequentes.
- [ ] Responder dúvidas no grupo.
- [ ] Publicar stories de reforço.
- [ ] Liberar link no Instagram após prioridade do grupo.
- [ ] Conferir pixel/eventos.
- [ ] Verificar abandono de checkout.
- [ ] Separar objeções reais.
- [ ] Atualizar FAQ.

## Dias seguintes

- [ ] Publicar prova nova.
- [ ] Mostrar por dentro do curso.
- [ ] Reforçar diferença entre WMC 1 e WMC 2.
- [ ] Publicar conteúdo técnico de sustentação.
- [ ] Rodar remarketing.
- [ ] Recuperar checkout abandonado.
- [ ] Analisar canal de origem das vendas.
- [ ] Atualizar relatório diário.
- [ ] Ajustar página se houver gargalo.
- [ ] Ajustar anúncio se CPL/CPA estiver ruim.
- [ ] Responder dúvidas recorrentes.

## Não fazer

- [ ] Não anunciar fechamento sem decisão manual.
- [ ] Não usar escassez falsa.
- [ ] Não dizer “última chance”.
- [ ] Não pressionar com urgência inexistente.
- [ ] Não mudar a promessa para vender mais rápido.
