# Checklist fechamento

## Manhã - responsável: marketing

- [ ] Enviar resumo técnico no WhatsApp.
- [ ] Publicar stories com FAQ.
- [ ] Reforçar para quem é e para quem não é.
- [ ] Evitar promessa ou pressão falsa.

## Tarde - responsável: suporte

- [ ] Responder dúvidas pendentes.
- [ ] Atualizar FAQ rápido.
- [ ] Sinalizar problemas de pagamento.
- [ ] Encaminhar dúvidas técnicas ao Saizen.

## Noite - responsável: coordenação

- [ ] Enviar último lembrete de fechamento real.
- [ ] Confirmar horário exato de encerramento.
- [ ] Fechar carrinho ou remover link conforme decisão.
- [ ] Salvar prints das métricas finais.
- [ ] Registrar aprendizado principal.

## Técnica - responsável: programação

- [ ] Conferir se a Kiwify fechou corretamente.
- [ ] Conferir entrega para últimos compradores.
- [ ] Remover CTAs públicos que prometem carrinho aberto.
- [ ] Guardar links finais em arquivo interno.
