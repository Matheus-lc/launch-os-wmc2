# Checklist compliance

## Posts

- [ ] A promessa é educacional.
- [ ] Não há resultado físico garantido.
- [ ] Não há renda garantida.
- [ ] O CTA é claro e honesto.
- [ ] Provas estão autorizadas.

## Anúncios

- [ ] Não usa antes/depois agressivo.
- [ ] Não usa linguagem de cura, milagre ou garantia.
- [ ] Não segmenta de forma sensível.
- [ ] Não cria urgência falsa.
- [ ] Link e oferta estão coerentes.

## Página

- [ ] Preço correto.
- [ ] Garantia correta.
- [ ] Aviso educacional presente.
- [ ] Para quem é e para quem não é estão claros.
- [ ] WMC1 como order bump está explicado.

## WhatsApp

- [ ] Mensagens não prometem resultado.
- [ ] Respostas não dão consultoria individual.
- [ ] Dúvidas profissionais são respondidas com cuidado.
- [ ] Fechamento usa urgência real.
