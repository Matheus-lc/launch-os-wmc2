# Checklist de revisão de copy

Use score de 0 a 2.

- 0: fraco ou ausente.
- 1: aceitável, mas precisa ajuste.
- 2: pronto para publicar.

## Critérios

| Critério | 0 | 1 | 2 | Nota |
|---|---|---|---|---|
| Clareza | Confuso | Entendível | Direto |  |
| Aderência à marca | Genérico | Parcial | Técnico e professoral |  |
| Especificidade | Vago | Tem tema | Tem contexto e detalhe |  |
| Credibilidade | Parece promessa | Precisa prova | Seguro e crível |  |
| Agressividade | Pressão alta | Tom misto | Convite firme |  |
| Compliance | Risco alto | Revisar | Seguro |  |
| CTA | Ausente | Fraco | Claro |  |

## Regra de publicação

- 12 a 14 pontos: publicar.
- 9 a 11 pontos: revisar antes.
- 0 a 8 pontos: reescrever.

## Perguntas finais

- A copy promete resultado físico garantido?
- A copy inventa prova?
- A copy parece guru?
- O CTA combina com a etapa do funil?
- A peça respeita o tom do Mr.Saizen?
